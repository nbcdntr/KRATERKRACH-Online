2. Welche Daten? / Data processed

  • On the device: local profile, tank selection, earned credits, upgrades, preferences, game sound setting, server address and a randomly generated device identifier are stored in browser storage (localStorage) or application storage.
  • On the multiplayer server: the identifier is hashed and associated with an automatically allocated, non-editable nickname; the server also stores registration time. Current beta code does not ask for real name or email.
  • During play: room code, public-in-room nickname, chosen tank, alliance requests, shots, movement commands, game state and other match events are processed and shared with participants in that private room. Live room state is held in server memory.
  • Hosting: the hosting provider may process connection metadata, including IP address, timestamps and technically necessary request logs. Exact hosting region, processors and retention periods must be checked for the deployed provider.

3. Warum? / Purposes and legal basis

These data are needed to operate the game, allocate non-editable usernames, prevent duplicate room seats, connect invited players and synchronize matches. For a free beta service, the intended legal basis is Article 6(1)(b) GDPR where processing is necessary to provide the requested service, or Article 6(1)(f) GDPR for technical security and abuse prevention where appropriate. The legal basis must be confirmed by the operator before release.

4. Aufbewahrung / Retention

Rooms expire after approximately two hours or when the host ends the room. The current beta uses a local SQLite identity registry and retains hashed device identifiers and associated nicknames until they are deleted or the registry is reset. The operator must implement and disclose an appropriate deletion/retention procedure before wider release.

Device data stays until deleted in browser/app settings or the app is removed. Hosting logs are retained under the selected provider's applicable policies.
